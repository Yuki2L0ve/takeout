# 荔园点餐系统
定位：专门为校园定制的一款软件产品
功能架构可分为**管理端**和**用户端**：
+ 管理端：员工管理、分类管理、菜品管理、套餐管理、订单管理、工作台、数据统计、来单提醒
+ 用户端：微信登录、商品浏览、购物车、用户下单、微信支付、历史订单、地址管理、用户催单

技术选型
+ 用户层：Node.js、Vue.js、ElementUI、微信小程序、Echarts
+ 网关层：Nginx
+ 应用层：SpringBoot、SpringMVC、Spring Task、Spring Cache、HttpClient、JWT、aliOSS、Swagger、POI、WebSocket
+ 数据层：MySQL、Redis、MyBatis、PageHelper、Spring Data Redis
+ 工具：Git、Maven、Junit、Postman

整体结构
+ 前端：管理端（Web）+用户端（微信小程序）
+ 后端：后端服务（Java）
